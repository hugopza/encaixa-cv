# Vacant sintètica per a la demostració

Títol: Frontend developer

Departament: Producte i tecnologia

Ubicació: Barcelona, híbrid

## Descripció per enganxar

Busquem un frontend developer per construir un portal de gestió amb React i TypeScript. Necessitem experiència pràctica en formularis, integració d'APIs, accessibilitat amb navegació per teclat i proves automatitzades. Es valoren projectes lliurats amb resultats mesurables i col·laboració amb disseny i backend. L'avaluació es basa en evidències del CV i es completa amb una entrevista.

## Criteris

| Criteri | Pes |
| --- | --- |
| Experiència pràctica amb React i TypeScript | 50% |
| Accessibilitat i proves automatitzades | 30% |
| Projectes lliurats i resultats demostrables | 20% |
